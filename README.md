# Pixel Lab IA: versões

Pacotes publicados do Pixel Lab IA. O app consulta o `atualizacao.json` e baixa o pacote de `versoes/`.

Para instalar pela primeira vez, baixe o [`PixelLabIA.zip`](PixelLabIA.zip), extraia e dê dois cliques em `Instalar Pixel Lab IA.bat`. Ele baixa a versão mais nova, instala e abre o app.
