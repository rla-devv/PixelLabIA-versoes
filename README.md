# Pixel Lab IA: versões

Pacotes publicados do Pixel Lab IA. Cada versão é uma [Release](../../releases) (tag `vX.Y.Z`) com o instalador e o pacote de atualização. O app consulta o `atualizacao.json` e baixa o pacote da Release (ou, se falhar, de `versoes/`).

Para instalar pela primeira vez, baixe o [`Pixel-Lab-IA.zip`](../../releases/latest/download/Pixel-Lab-IA.zip), extraia e dê dois cliques em `Instalar Pixel Lab IA.bat`. Ele baixa a versão mais nova, instala e abre o app. (O [`Pixel Lab IA.zip`](Pixel%20Lab%20IA.zip) desta pasta é o mesmo instalador, para os links antigos.)
